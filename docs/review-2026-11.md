# Code review 2026-11: Biome work items

Work items from the November 2026 Forest + Biome code review, linked from
`docs/roadmap.md`. Each item is one PR into `develop` unless marked
"develop" (small enough to commit directly). IDs (`B2-3`, `X1-1`, …) name the
review findings, which live outside the repo. When an item ships, delete it
here and its roadmap entry. Effort is S/M/L; "manual" means the user has to
test it interactively.

Headless repro harnesses from the review (nested/headless biome, fake
keyboard shim, portal scripts) are in the review's `tools/headless/`; the
recipe is a private `dbus-run-session`, a short `XDG_RUNTIME_DIR`,
`WLR_BACKENDS=headless WLR_RENDERER=pixman WLR_LIBINPUT_NO_DEVICES=1`.

## 0.3.x fixes

### xwayland-state
**Xwayland window state and decoration cache.** B2-6, B5-2. S. Headless
(`xfs` client).
- X11 windows come back from fullscreen with no frame and shifted content:
  the undecorated branch (`decoration_bridge.cpp:148-156`) doesn't
  invalidate the skip-cache. Reset `decoration_rendered_once` there and on
  unmap; key the title (and icon) on serials, not pointers (ABA).
- `request_configure` is honoured while maximized/fullscreen/snapped; ignore
  geometry then. Clamp interactive resize to `WM_NORMAL_HINTS`. Listen to
  `set_decorations` and take the `apply_decoration_change` path.

### client-conformance
**Standard-protocol gaps for other shells' clients.** B4-3, B4-5, B4-6,
B4-8, S0-11 (redundant init). S–M. Prioritised by the decoupling goal (X1-13).
- A layer surface that unmaps with a null buffer never gets a configure for
  its re-initial commit and hangs (`layer_shell.cpp:233-235`): configure on
  `initial_commit`; re-arrange on unmap of an exclusive surface.
- ext-foreign-toplevel-list handles start with empty title/app_id that stay
  empty (`foreign_toplevel.cpp:133-143`): create the ext handle with the real
  strings (wlr handle still first for pairing).
- Each new layer surface reconfigures every surface on the output twice
  (B4-6): drop the creation-time arrange; configure only the committing
  surface unless an exclusive zone, layer or output geometry changed. Verify
  with `WAYLAND_DEBUG` while a notification pops.
- Scanout fades assume a full-output surface (B4-8): fall back to Opacity
  otherwise; drop the snapshot on an output size change.

### output-failures
**Output failure paths.** B3-5, B3-8, B3-7 (rescue rebase). S.
- A failed first modeset still adds the output as live (`output.cpp:411,422`):
  retry with the preferred mode, else keep it disabled and publish that.
- One `output_layout_changed_by(cause)` for the four repeated
  relayout/settled/publish epilogues.
- `cursor_rebase` after `rescue_cursor`.

### lock-followups
**Session-lock follow-ups.** B1-3, B4-7, B4-9a/b/e, B2-11. S–M. Manual: lock
with Alt-Tab held / a menu open.
- Add a fixed `layers.osd` tree between `fullscreen` and `session_lock` for
  the switcher, window menu and drag icon (today above the lock, B1-3); fix
  the "structurally topmost" comments.
- Blank per-window capture while locked (B4-7, decided, low priority).
- Red rect for outputs added during an abandoned lock (a); `cursor_rebase`
  on unlock (b); refuse new `xdg_popup` grabs while locked (e).
- Drop the per-site `session_locked` focus guards now that
  `grant_keyboard_focus_to_non_toplevel` carries it (B2-11).

### robustness
**Shutdown and event-loop robustness.** B1-9, B1-6. S. Manual: logout.
- Handle SIGTERM/SIGINT with `wl_display_terminate` so logout runs the
  teardown fixed in 0.3.0; kill the `-s` child on non-child exit.
- `qt_glib_bridge` `sync_fd_sources`: re-add a source when
  `wl_event_source_fd_update` fails (fd number reused within a cycle).

## 0.4.0

### server-split
**Per-subsystem server state.** B1-2, B3-10, B4-12, B5-9, B5-10, B1-7, B1-4
(dead `lock_tree`), B1-11, B2-12, B3-12, B4-11, B5-11 (comment trims),
S0-6, X1-2, B3-11 (items 2-6). L. Do after the 0.3.x fixes.
- `BiomeServer` (~118 fields, 75% single-module) becomes embedded
  sub-structs (`xdg`, `layer`, `lock`, `activation`, `idle`, `grab`, `snap`,
  `outputs_mgmt`, `keys`, `osd`, …), each owning its listeners and an
  `X_finish()` called in reverse init order (structurally prevents the
  0.3.0 teardown abort). `wl_container_of` on standard-layout sub-structs
  also removes the `-Winvalid-offsetof` warnings.
- File statics (window menu, keybindings, snap, switcher/menu Qt roots) move
  in. Move `set_decoration_buffer` to `desktop/qt_buffer`, share the OSD-node
  and icon→`QIcon` helpers (B5-9). Cache both states' decoration metrics per
  theme load instead of restyling the widget per getter (B5-10).
- Capture globals created in one place (B1-7). Trim the narrative header
  comments to the terse rule while touching them.
- Port `ext_workspace.cpp` to wlroots 0.20's `wlr_ext_workspace_v1` with
  `id = "<index>"` and `coordinates` (X1-2); Forest keys on the id
  ([forest `workspace-ids`]), either order.
- First: a headless integration ctest (teardown with `-s`, remap, unplug
  while locked, lock-with-outputs-off, fake-keyboard lock focus) plus the
  pure-helper tests (modifier-tap `step()`, relayout planning,
  `head_layout_box`, `parse_mode`, `rgb_range` in `output_config_test`).

### watchers
**Theme/cursor/icon watchers.** B5-7, B1-8, X1-7, X1-8, B5-8. S–M.
Manual: change cursor theme; edit qt6ct.conf.
- One debounced `watch_path()` helper for both watchers (B5-7);
  `theme_watcher` does the initial load (B1-8).
- Cursor contract (X1-8): `~/.icons/default/index.theme` `Inherits=`
  (+ `Size=`, a Forest/Biome convention) is authoritative and preferred at
  startup; `XCURSOR_*` only when absent. Refresh the Xwayland cursor. Record
  it in architecture-notes.
- qt6ct (X1-7, decided: keep following it): confirm it sets the titlebar
  font, then watch `qt6ct.conf` → `reload_decoration_theme()`; document it.
- App icons (B5-8): cache-owned rasters handed out by pointer; re-resolve on
  `set_app_id`/icon change; clear caches on icon-theme change.

### theme-coupling
**Theme-format version coupling.** X1-10. S. Pairs with Forest 0.11.2
(`ForestThemeConfigVersion.cmake`) and 0.12.0 (theme CSS consolidation).
- `find_package(ForestTheme 0.11 REQUIRED)`, `BuildRequires:
  cmake(ForestTheme) >= 0.11` (spec + debian).
- Regenerate `builtin.qss` from base + base-rounded + base-dark
  `biome.css`/`shared.css` once Forest's CSS consolidation lands
  (`palette()` resolved to literals).
- A theme with no `biome.css` in any layer counts as unusable (falls back to
  `builtin.qss`).

### decoration-strips
**Edge-strip decoration buffers.** B5-3. M. Manual visual check of corners
at 1.0/1.5/2.0 scale (decided: try it).
- Every uncached decoration change (button hover, focus, title, resize step)
  renders and uploads a full-window buffer: ~30 ms and 33 MB for a maximized
  4K window. Render titlebar + border strips instead (title/hover changes
  touch only the titlebar), wrap the `QImage` in the `wlr_buffer` without a
  copy, and cache the Alt-Tab highlight per size.
